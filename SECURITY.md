# Security Policy

## Reporting a Vulnerability

Please **do not** open a public issue for exploitable vulnerabilities.

- Report privately via GitHub Security Advisories on this repository, or
- Contact the maintainer directly: [@Hikmaholadele](https://github.com/Hikmaholadele).

We aim to acknowledge reports within 7 days.

## Status

**v0.1.0 — not audited, not production-ready.** Do not deploy with real funds.
